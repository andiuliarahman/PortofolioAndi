TARUH FILE MUSIK DI SINI
========================

Nama file yang dibaca oleh web:  bgm.mp3

Taruh satu file MP3 di folder ini dengan nama persis "bgm.mp3", lalu push.
Tombol musik di pojok kiri bawah akan otomatis aktif.

Kalau file belum ada, tombol tetap muncul tapi berstatus "musik belum
tersedia" (ikon not balok abu-abu) -- web tidak error.


PENTING SOAL HAK CIPTA
----------------------
Lagu berhak cipta (misalnya milik Hindia, atau lagu komersial lain)
TIDAK boleh dipasang di website publik tanpa izin/lisensi dari pemegang
hak. Mengunggah file MP3 lagu komersial ke GitHub Pages termasuk
pelanggaran hak cipta, dan bisa berujung pada takedown atau teguran.

Pilihan yang aman:
  1. Pakai musik berlisensi bebas (royalty-free / Creative Commons)
     - Pixabay Music, Uppbeat, Free Music Archive, Bensound
     - Cek lisensinya: sebagian wajib mencantumkan kredit.
  2. Pakai rekaman milik sendiri (mis. hasil Envilm Production).
  3. Sematkan player resmi Spotify/YouTube (legal, tapi bukan musik latar).


CATATAN TEKNIS
--------------
- Volume default 35% supaya tidak menutupi percakapan.
- Musik TIDAK autoplay -- pengunjung harus klik tombol. Ini disengaja:
  browser modern memblokir audio bersuara tanpa interaksi, dan rekruter
  yang membuka portofolio di kantor biasanya tidak ingin tiba-tiba ada suara.
- Musik berulang terus (loop).
